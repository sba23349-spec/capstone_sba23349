# Predicting Airline Departure Delays Using Machine Learning

## Project Overview

This Capstone Project investigates the prediction of airline departure delays using machine learning techniques, with the aim of supporting airline operational planning and decision-making.

## Business Problem

Airline departure delays can cause operational disruptions, additional costs and customer dissatisfaction. Identifying flights at risk of delays could help airlines make more informed operational decisions.

## Dataset

- Source: US Bureau of Transportation Statistics (BTS)

- Dataset: Airline On-Time Performance Data

- Number of records: 582,425

- Number of columns: 17

- Target variable: DEP_DEL15 (departure delay of 15 minutes or more)
